# 오늘 로고와 채팅 진입 버튼

## 작업일지

공도리 로고를 오늘 탭의 왼쪽 도구 막대로 옮겼다. 비서 답변·초안·대화에서 글마다 붙던 로고와 아이콘용 여백은 제거했다. 탭 바 위의 텍스트 버튼과 VoiceOver 이름은 `채팅하기`로 통일했다.

## 코드리뷰 메모

채팅 버튼과 마이크는 별도 동작을 유지한다. 채팅 버튼은 기존 식별자 `assistant.accessory`를 그대로 쓰며, 설정의 `비서에게 맡길 일`과 채팅 입력창 `무엇이든 물어보세요`는 변경 대상이 아니다. 탭 내비게이션 UI 테스트에 오늘 로고의 위치와 채팅 버튼 이름 검사를 추가했다.

## QA 결과

라이트·다크 모드에서 홈 브랜드 및 채팅 화면 검사와 탭 이동 후 채팅 진입 검사를 실행했다. 각 모드에서 2개씩 통과했다. 홈 상단에는 로고가 한 번 표시됐고, 하단 `채팅하기`로 연 대화에서는 저장된 답변이 로고 없이 표시됐다. 테스트는 로컬 서버와 시뮬레이터용 임시 복사본에서 수행했다. 기존 `GeneratedText.swift` SDK 호환 조정은 저장소에 포함하지 않았다.
